Get a worker going

A machine with Python 3 and this server's address is all it needs. It registers itself, and waits to be approved here, or comes with a join code.

curl -fLo client.zip {{ server }}/client.zip
python3 -m zipfile -e client.zip nyayo-worker
python3 -m pip install -r nyayo-worker/requirements.txt
python3 nyayo-worker/client.py --server {{ server }} -T 4 -N 1 -I my-machine

-T is the threads it may use, -I its name here. With a code from the join codes below, add --join CODE and it is approved when it says hello. On Windows use py for python3, and Invoke-WebRequest {{ server }}/client.zip -OutFile client.zip for curl. To build engines it needs make and a C or C++ compiler. The client updates itself from here when the version goes up, and keeps its worker.token.
